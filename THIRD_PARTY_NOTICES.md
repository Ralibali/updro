# Third-party interoperability

## OpenOutreach

- Source: https://github.com/eracle/OpenOutreach
- Reviewed revision: `b8bb2e36c0b30ff885bd5899d43b27bdad7ee3bd`
- License: GPLv3

Updro accepts the public CSV/JSONL interchange fields documented by
OpenOutreach (`email`, `first_name`, `last_name`, `company`, `title`,
`website`, `linkedin_url`, `reason`, `lead_id`, `qualified_at`). No GPL source
code or Python package is copied or bundled. OpenOutreach remains an external
worker; Updro adds its own review, approval and export layer.
